Balance test - rock paper scissors

Simulates the real game engine without rendering and without touching your save (isolated in-memory storage). Default config: no upgrades, no power-ups, no capture.

How the tests work (click to collapse)

Full campaign

Simulates 1000 real matches (10 runs x 100 levels) at full speed and computes the win % of each race. Perfect balance = 20%; ±5pp (15-25%) is considered ok.

This is the verdict test. Always run it with Runs 10 and Levels 100 so it is comparable across changes. Look at the "Verdict" section of the report.

Matchup 1v1

Puts each chaser against its prey in pure pursuit (12 attempts) and measures win % and average time to kill (TTK). A 0% = that chaser cannot catch its prey in pursuit (it only kills in clusters).

Fast (~10s). Good for explaining campaign behavior, not for direct tuning.

Sensitivity sweep (Jacobian)

Measures a baseline and then changes ONE stat ±15% at a time (the rest unchanged), re-simulating each time. The results table is the Jacobian: how many percentage points (pp) each race's win rate moves when each stat is touched.

This tells you which lever to turn and in which direction. With 1 run x 60 levels the noise is high; use 5x200 for reliable figures.

Main test verdict

1000 full matches of the real game. This is the report that decides whether the balance is right.
